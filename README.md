## 🚀 Projetos em Destaque

### 🌱 [Reflora – Environmental and Agricultural Monitoring]

> _Full-stack system to assist farmers in real-time monitoring of essential soil parameters._

- 🎯 **Desafio:** Criar um sistema full-stack para auxiliar agricultores no monitoramento em tempo real (umidade, temperatura, pH), visando otimizar a tomada de decisão.
- 🛠 **Minha Atuação:** - Arquitetei a API RESTful em **Node.js/Express** para ingestão de dados dos sensores.
  - Modelei o banco **PostgreSQL** utilizando **Drizzle ORM** para garantir type-safety.
  - No frontend, implementei dashboards em **React Native** com alertas automáticos.
- 🏆 **Resultado:** Processamento de dados em tempo real, permitindo resposta rápida a condições críticas do solo.
- **Techs:** React Native, Node.js, PostgreSQL, Drizzle, TypeScript.
