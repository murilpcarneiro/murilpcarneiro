## 🚀 Featured Projects

### 🧠 [HealthSense – Customer Health Score with Fuzzy Logic]

> _Fuzzy inference system (Mamdani) to calculate a health score for B2B SaaS customers._

- 🎯 **Challenge:** Translate qualitative and quantitative product usage signals into an explainable customer health score.
- 🛠 **My Role:** Modeled 5 linguistic input variables and a 32-rule fuzzy inference base with centroid defuzzification, plus an interactive dashboard in **Streamlit**.
- 🏆 **Outcome:** An interpretable, visually auditable health score, backed by a complete technical report documenting the fuzzy reasoning.
- **Tech:** Python, Fuzzy Logic (Mamdani), Streamlit.

<br>

### 💰 [PriceWatch – Price Comparison App]

> _Full-stack application to track and compare product prices in real time._

- 🎯 **Challenge:** Build a resilient price-scraping pipeline after the original Mercado Livre integration hit certification barriers.
- 🛠 **My Role:** Migrated data collection to **SerpApi (Google Shopping)**, kept the API on **Node.js/Express/Prisma**, and the frontend on **React + Vite**, deployed on **Render**.
- 🏆 **Outcome:** A functional price comparison tool, resilient to third-party API changes.
- **Tech:** Node.js, Express, TypeScript, Prisma, PostgreSQL, React, Vite.

<br>

### 🌱 [Reflora – Environmental and Agricultural Monitoring]

> _Full-stack system for real-time monitoring of essential soil parameters._

- 🎯 **Challenge:** Build a full-stack system to help farmers monitor soil conditions (humidity, temperature, pH) in real time, optimizing decision-making.
- 🛠 **My Role:** Architected the RESTful API in **Node.js/Express** for sensor data ingestion, modeled the **PostgreSQL** database with **Drizzle ORM** for type-safety, and built **React Native** dashboards with automatic alerts.
- 🏆 **Outcome:** Real-time data processing, enabling fast response to critical soil conditions.
- **Tech:** React Native, Node.js, PostgreSQL, Drizzle, TypeScript.
